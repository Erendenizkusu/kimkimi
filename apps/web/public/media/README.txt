KimKimi — `public/media` GIF’leri
================================

Dosya adları kodda tanımlıdır; sunucuda büyük/küçük harf duyarlı olabilir.

Dosyalar ve kullanıldıkları yerler
-----------------------------------
| Dosya | Nerede |
|--------|--------|
| **weSee.gif** | Oda — profil giriş bandı (metnin altında). |
| **doYouKnow.gif** | Oda — oyuncu bekleniyor; «Koda katıl» modalı. |
| **waitAMinute.gif** | Oyna sayfası üst süsü; kahraman arka plan yedeği. |
| **whoAmI.gif** | Kahraman arka plan yedeği. |
| **whoAreU.gif** | Kahraman arka plan yedeği (sıranın sonunda). |
| **sayMyName.gif** | Oyun bitti — kazanan kutlaması. |
| **hero.gif** | Ana sayfa kahraman arka planı (kutuyu tamamen doldurur, kenarlardan kırpılır — ilgi merkezi ortada olsun). |

Yedek adlar (404 olursa otomatik denenir): `WeSee.gif`, `DoYouKnow.gif`, `WaitAMinute.gif`, `WhoAmI.gif`, `whoareu.gif`, `SayMyName.gif`.

İsteğe bağlı: `.env.local` → `NEXT_PUBLIC_HERO_GIF_URL`.

Telif: Yalnızca kullanma hakkın olan içerik.
